# Cauan — vídeo e fotografia

Site estático com apresentação cinematográfica e câmera em ilustração 3D.

## Executar e publicar

Abra index.html ou execute npm install e npm run dev.
npm run build gera a pasta dist para hospedagem estática.
Na Vercel: preset Other, build npm run build, saída dist.
O site não precisa de chave Gemini nem de outras chaves de API.

## Editar

Conteúdo e mídias: index.html e assets/.
Animação cinematográfica: cinema.js e cinema.css.
Demais estilos e interações: style.css e app.js.
Câmera: assets/camera-cinema-3d.webp, ilustração conceitual 3D transparente.

A galeria fixa seu palco durante o scroll. Cada filme expande, permanece em destaque, recolhe e dá lugar ao próximo. A sequência é reversível. Há controles de som, pausa, tela cheia e pular apresentação. Movimento reduzido oferece galeria com controles nativos.

Vídeos e demais imagens preservados do ZIP fornecido.
